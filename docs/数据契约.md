# 数据与业务契约

estimate 按源量表方向保留，outcome 是报告使用的名称，scale.construct 才说明测量概念，两者不能直接视为相同。correlation=null 表示未报告而非零。study 及 population 标识独立来源，共用 arm 的对比不是独立人群。

## 数据集合

- `studies`：主键为 `study`；必填字段 `study, institution, design, population, sample`，当前 12 条。
- `arms`：主键为 `arm`；必填字段 `arm, study, kind, enrolled, observed`，当前 28 条。
- `effects`：主键为 `effect`；必填字段 `effect, study, population, control, treatment, outcome, scale, followup_weeks, estimate, standard_error`，当前 22 条。
- `scales`：主键为 `scale`；必填字段 `scale, construct, higher, range`，当前 2 条。
- `publications`：主键为 `publication`；必填字段 `publication, study, effect, year`，当前 22 条。
- `decisions`：主键为 `decision`；必填字段 `decision, scope, status`，当前 1 条。

集合中的主键不得重复；schema 的 foreign 引用须指向已存在的记录。可空字段保留 null 的业务含义，不自动补零。

## 查询与材料

GET 查询使用 UTF-8 JSON，错误参数返回 400，不存在的接口返回 404。重复的单值参数视为无效。summary 与 HTTP 调用同一组只读计算，材料包含数据内容指纹和生成时间，便于核对输入。当前输出描述已有数据，不承诺未实现的推断结论。

## 证据合成

`/api/synthesis` 与 `/api/evidence` 的 synthesis 字段按统一规则（synthesis-v1）合成证据，可选参数 `service`、`exclude_institution`、`correlation`（加入敏感性网格的假定相关系数，取值 [0,1)）：

- 合并单位是独立人群（population）。同一人群的反复测量（如结课与 12 周回访）和共用对照臂的对比不算独立证据，不按独立研究平均；dependencies 段逐一列出这些相依结构。
- 只在含义相容的层内合并：同一服务（臂 kind）、同一 construct、同一 scale、同一随访时间。合并前把方向统一为"正值代表获益"。不同 construct 的结果各自保留展示，绝不硬塞进同一个总效果；grand_total.computed 恒为 false。
- correlation=null 表示未报告而非零。凡涉及相依结果的合并，输出在假定相关系数网格上的敏感性（合并值、标准误、结论是否翻转），绝不悄悄按完全独立处理；主合成通过分层避免使用未报告的相关系数。
- 小样本（臂观测人数 <20）、失访（>10%）与机构集中度列入 confidence；leave_one_institution_out 给出剔除每个机构后的结论变化，fragile=true 表示结论依赖单一机构。
- 观察性研究单独分层汇总，causal_interpretation 标明是否存在随机化子集；观察性材料不因汇总获得因果含义。
- publications 段说明每份材料相对已有对比增加了什么（新独立对比、同一人群延长随访、共用对照的额外臂、重复引用）；合成权重只来自独立人群与标准误，材料数量不增加权重。
- 每层结论可回到具体对比（control/treatment 臂）与人群；decisions 段给出待决事项当前证据支持的办理类型。

## 现有办理协作

人工选择研究与地区形成推广提案，pilot_funds.approve 在地区预算内审批，pilot_agreements.sign 按获批地区和范围签署参与确认。三个环节共用同一份证据基线（数据指纹 + supported_kind + 各层结论）：

- recommendations.propose 计算证据基线并确定办理类型：kind 缺省按证据定为 promote 或 evidence_pilot；证据不足时请求 promote 会被拒绝。地区缺少适用证据只能提出补证试点，不能包装成已证明有效的全面推广。
- pilot_funds.approve 要求提案基线与当前数据指纹一致，否则拒绝并需重新提案；审批记录本地适用条件（地区学校、证据来源机构、注意项；研究未按地区标记，region_matched_studies 恒为 false）。升级前留下的无基线提案按当前合成补盖基线，类型按 evidence_pilot 处理。
- pilot_agreements.sign 只在新签时校验基线：某机构剔除等数据变化使建议不再成立时，尚未确认的试点不能沿用旧依据；已签署的确认是历史记录，重复签署原样返回，新汇总不会删除或改写。
- pilot_agreements.audit 列出提案、拨款与签署记录及各自基线是否仍然有效（basis_current），供委员会核对三个环节的证据一致性。

每个操作在本地业务日志的事务中更新；失败不提交半条办理记录。接口传入业务标识，未知标识或不满足条件返回错误，不自动补建对象。
